## A Framework for Deterministic Data Grounding

This repository serves as the official machine-readable reference implementation for the **Logic RFC™** protocol. It is designed to meet the **Technical Control** requirements of the **EU AI Act (Article 11 & 12)** and the **2026 NIST AI Agent Standards (Identity & Authorization Focus)**.

### 🎯 The "IfThenWhy" Intent
The **IfThenWhy™** framework prioritizes **Intent over Infrastructure**. It ensures that every AI-generated action is mathematically tethered to a human-signed business requirement, preventing **Logic Drift** and unauthorized autonomous actions.

### 📂 Repository Structure (The 6-File Logic DNA™)

1. **MAN (Metric Manifest):** - **Function:** The Identity Anchor and Version Control.
   - **NIST Alignment:** Implements **Automated Activity Logging**.

2. **SEM (Semantic Layer):** - **Function:** The "Business Why" and Persona Anchor.
   - **NIST Alignment:** Provides **Human Factors Monitoring**.

3. **BRG (Bridge File):** - **Function:** The **Permission Handshake** and Kinetic Link.
   - **NIST Alignment:** Serves as the **Authorization Protocol** for agentic intent.

4. **LDD (Logical Data Design):** - **Function:** The "Hardened Math" and Validation Logic.
   - **NIST Alignment:** Enforces **Input Validation & Predictable Behavior** (NIST SP 800-53 SI-10).

5. **DIC (Data Dictionary):** - **Function:** The physical **Supply Chain Provenance** map.
   - **NIST Alignment:** Ties logical entities to physical source-to-target mappings.

6. **LUT (Lookup Tables):** - **Function:** The **Universal Translator** for categorical hierarchies.
   - **NIST Alignment:** Prevents "Hallucinated Categorization" during agentic reasoning.

### 🛡️ SQL_Lock: The 5-Second Audit Protocol
This repository includes a reference Python implementation that acts as a **Digital Deadbolt** for SQL execution. It verifies **BRG** authorization and validates math against the **LDD** to ensure **Non-Repudiation**.
